# NTUCC 公開網站配置盤點與 FJUBAC 建議

## 盤點範圍與限制

本盤點僅涵蓋 [NTUCC 公開首頁][1]、[課程規劃][2]、[學習資源][3]、[專案成果][4]、[活動成果][5]、[招募資訊][6] 與 [幹部成員][7] 可見內容。公開網站並未揭示其後台、帳號、權限、資料庫或內容審核流程，因此不對這些未公開能力作推論。

## 可觀察到的網站配置與功能

| 配置／功能 | NTUCC 公開呈現 | FJUBAC 現況 | 建議 |
|---|---|---|---|
| 品牌首頁 | 標語、願景、核心價值、年度課程與專案概覽、成果摘要。 | 已有品牌首頁、五部門與最新資訊。 | **保留既有方向**，以真實公告與活動充實內容。 |
| 課程規劃 | 以學期、技能與職涯主題呈現年度培訓。 [2] | 有活動與資源，但未有公開年度學習地圖。 | **建議加入**「年度學習與活動地圖」公開頁。 |

| 專案成果集 | 以年度與題目列出成果卡片。 [4] | 已有專案與專案指派，但未有公開成果展區。 | **建議加入**「公開專案成果」欄位與作品集頁；須由專案負責人核准公開。 |

| FAQ | 首頁含招募、資格、時間與參與方式問答。 [1] | 尚無公開 FAQ 模組。 | **建議加入**招生、社員、活動三類 FAQ。 |

## 活動日曆與 Google Calendar 方案

FJUBAC 現有活動模型和後端授權已能限制具活動管理權限的幹部建立、修改與取消活動；所有登入成員可依其會員、專案與職務範圍檢視活動。建議新增「月／週／清單」行事曆視圖，但**不改變既有後端的管理權限**。

| 能力 | 建議第一階段 | 是否需 Google API／帳號授權 |
|---|---|---|
| 網站行事曆 | 直接讀取既有活動資料，成員依權限瀏覽、查詢與開啟詳情。 | 否 |
| 加入個人 Google 日曆 | 在活動詳情提供「加入 Google 日曆」連結與 `.ics` 下載；Google 會由使用者自己的帳號開啟與儲存。 | 否 |
| 個人提醒 | 由使用者加入自己的 Google 日曆後，在 Google 日曆中設定提醒；網站可說明此步驟。 | 否 |
| 官方共用日曆雙向同步 | FJUBAC 活動與一個官方 Google Calendar 同步。 | 是；需社團 Google 帳號、OAuth／Calendar API 與明確同步規則。 |

目前工作階段的 Google Calendar 整合為停用狀態；而部署網站的第一階段採 ICS／Google Calendar 範本連結即可滿足「加入自己的日曆與個人提醒」需求，不需要將任何個人 Google 帳號資料交給網站。若日後要做官方共用日曆同步，再另行取得社團帳號與 OAuth 設定確認。

## 建議實作順序（待確認）

| 優先級 | 功能 | 理由與前提 |
|---|---|---|
| P0 | 修正全站文字對比、正式頁尾 | 直接回應可讀性問題；頁尾需要真實社群連結與信箱。 |
| P1 | 活動月／週／清單日曆、搜尋、ICS 與 Google 加入連結 | 直接回應活動管理與成員行事曆需求；沿用現有權限。 |
| P1 | 招生 FAQ 與梯次時程頁 | 直接使用現有招生資料，降低重複詢問。 |
| P2 | 公開資源精選與公開專案成果集 | 需補充公開授權、封面、摘要與公開日期資料。 |
| P2 | 部門／幹部公開介紹 | 需取得被介紹者公開同意與照片／連結。 |
| P3 | 已驗證的成果數據、活動回顧與社員心得 | 僅能使用真實、已同意公開且可追溯的資料；不得建立虛構評價或成果數據。 |

## 需要使用者確認或提供的資訊

正式頁尾不能假設社群帳號或聯絡信箱。請提供要公開的 Instagram、Facebook、LinkedIn、Medium／網站等連結，以及聯絡信箱；若某個平台沒有官方帳號，將不顯示該圖示。另請確認是否同意優先實作上述 P0 與 P1 功能，並選擇活動日曆採「第一階段 ICS／Google 加入連結」或「另行規劃官方 Google Calendar 同步」。
