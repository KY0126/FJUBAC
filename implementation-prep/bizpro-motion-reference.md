# BizPro 公開網站：品牌節奏與互動參考

## 可見觀察

於 2026-08-26 檢視 [BizPro 台大商學研究社公開網站](https://www.bizpro-taipei.com/)；首頁可見大型中心識別、短句主標、明確的「下滑瀏覽」提示、簡潔頂端導覽，以及以大面積留白和圖形符號分隔段落。其資訊架構將社團介紹、學習旅程、歷屆成員與心得分為獨立入口。

## FJUBAC 採用邊界

FJUBAC 將只採用「品牌識別優先、段落節奏清楚、捲動導引明確」的互動原則，不複製 BizPro 的紅色識別、圖形資產、文案、數據、合作企業或成員資訊。FJUBAC 會延續既有深靛藍、校徽藍與社徽，並以 `prefers-reduced-motion` 作為所有非必要視覺動態的前提。

## 本輪設計決策

| 元件 | FJUBAC 實作方向 |
| --- | --- |
| 初始載入 | 社徽與 FJUBAC 字標在深靛藍載入幕中短暫顯示，資料就緒後淡出。 |
| 路由轉場 | 以深靛藍遮罩和社徽徽記建立短暫離場／進場節奏，避免空白閃屏。 |
| 捲動導引 | 只在首頁主視覺及學習地圖提供低干擾提示，並可鍵盤操作。 |
| 卡片與按鈕 | 採短暫 hover、focus、active 回饋，不使用常駐粒子或高頻動畫。 |
| 可近用性 | 減少動態偏好下不播放載入、轉場、位移與持續動畫，內容立即呈現。 |
