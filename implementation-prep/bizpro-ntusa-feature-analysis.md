# BizPro Taipei 與臺大學生會公開網站功能盤點

## 研究範圍與判讀原則

本文件僅記錄公開可見的頁面、導覽、內容模組與前端互動線索。任何未公開的後台、帳號權限、資料來源、表單審核或自動化流程皆不作推論。

## BizPro Taipei 初步盤點

| 面向 | 公開可見內容／線索 | 對 FJUBAC 的啟示 |
|---|---|---|
| 主導覽 | 關於 BizPro、學習旅程、歷屆成員、成員心得。 | 可將 FJUBAC 的公開資訊逐步擴充為「關於、學習／活動、成果、社群」的層次，但不應複製其資訊架構。 |
| 品牌首頁 | 社團起源、願景、核心價值、社群影響力、專業訓練與社員連結。 | FJUBAC 既有首頁可優先補齊可驗證的年度學習與活動資訊；所有成果數字必須真實且可追溯。 |
| 成長內容 | 學習旅程、歷屆成員、成員心得為獨立入口。 | 可考慮公開版「學習地圖」與經同意公開的專案／校友成果；不得製作虛構社員心得。 |
| 信任元素 | 以企業 Logo 呈現社群／合作影響力。 | 只在取得合作或使用授權且可核實時加入 FJUBAC 合作單位／活動夥伴展示。 |
| 視覺與動畫線索 | 首頁含「下滑瀏覽」提示、裝飾性連結／圓形 SVG、重複 Logo 跑馬燈素材與章節圖形。 | 可借鏡克制的捲動提示、低干擾章節入場與合作夥伴帶；FJUBAC 應遵守減少動態偏好，避免為裝飾而增加負擔。 |
| 聯絡與社群 | Facebook、Instagram、Email 及頁尾版權資訊。 | FJUBAC 已新增 Instagram、Threads、LinkedIn；正式信箱待提供前不應猜測或顯示。 |

### BizPro 子頁補充

| 子頁 | 公開可見內容／功能 | 對 FJUBAC 的適用限制 |
|---|---|---|
| 學習旅程 | 以 Junior、Senior、Alumni 階段切分，並將課程依 Info-In、Info-Process、Info-Out 描述為圖文學習階段。 | 可做為真實社課、分析方法、專案實作與成果發表的「學習地圖」參考；內容應由學術營運部確認且不得將尚未開設的課程預先承諾。 |
| 歷屆成員 | 提供科系、領域、屆數篩選與關鍵字搜尋。 | 僅能在成員同意、隱私規範和維護責任完備後推出公開名錄；初期可先做較安全的「經同意公開之專案／成果」而非個人資料庫。 |
| 成員心得 | 以校友職涯／自我學習心得為內容，提供科系與領域條件篩選。 | FJUBAC 不應建立示範或虛構心得；只有取得作者同意、完成審稿並標示發布日期時才可推出。 |

來源：[BizPro Taipei 首頁](https://www.bizpro-taipei.com/)。

## 臺大學生會初步盤點

| 面向 | 公開可見內容／線索 | 對 FJUBAC 的啟示 |
|---|---|---|
| 單頁導覽 | Home、About、Announcements、Links、Records 使用錨點式主導覽。 | FJUBAC 可保留多頁服務架構，同時在首頁加入更明確的錨點捷徑；不必將既有功能強制改為單頁。 |
| 核心定位 | Hero 清楚呈現組織名稱、代表性與權益／民主使命。 | FJUBAC 可補強一段簡潔的年度使命與核心受眾說明，維持商業分析與實作定位。 |
| 最新訊息 | 以封面圖、分類、日期、標題、摘要與閱讀全文連結展示最新公告，另有查看全部入口。 | 建議優先新增「公告封面圖（可選）」與「分類／日期」的卡片規格；內容需由授權部門發布，維持現有權限。 |
| 連結中心 | 導覽含 Links 與 Records，將常用表單、服務或紀錄集中。 | FJUBAC 可規劃公開「連結與資源中心」，集中招生、活動、社群及經核准公開的資源，避免首頁資訊過載。 |
| 語言與可近用性 | 提供中／EN 語言切換控制。 | 若未來有足夠維護人力，可將招生與社團介紹逐步雙語化；不建議在無內容維護責任前先做空白切換。 |
| 維運入口 | 可見 Admin sign in 與兩種 Email（一般聯絡、問題回報）。 | FJUBAC 已有受保護工作台；待正式信箱提供後，可考慮區分一般聯絡與網站問題回報，但不應在未有人負責前公開。 |
| 視覺與動畫線索 | 首屏有 Canvas 背景、捲動提示、固定導覽與卡片式公告；公開頁面未顯示高干擾動畫。 | 可借鏡低干擾背景動態或捲動提示，但應以 CSS、無障礙與 `prefers-reduced-motion` 為前提，避免引入耗能 Canvas 效果。 |

補充：直接開啟網站的 `#forms` 錨點時，公開文字擷取仍以首頁導覽與最新公告為主，未取得可獨立核實的表單內容。因此僅將其視為「Links」導覽入口存在的公開線索，不推測表單清單、後台或資料處理流程。

來源：[臺大學生會首頁](https://ntusa.ntu.edu.tw/)。

## 初步整合建議（等待確認後才實作）

| 優先級 | 建議功能 | 參考來源 | 對 FJUBAC 的適用方式與限制 |
|---|---|---|---|
| P0 | 公告分類、日期與可選封面圖 | 臺大學生會 | 延伸既有公告程序；封面圖需使用儲存服務並保留無圖版面。 |
| P0 | 公開連結與資源中心 | 臺大學生會 Links | 將招生、活動、社群和已授權公開資源集中；不可放入僅供社員的檔案。 |
| P1 | 年度學習／活動地圖 | BizPro 學習旅程 | 以 FJUBAC 真實社課、專案與活動串聯；不使用虛構時數、成果或合作方。 |
| P1 | 經同意公開的專案／校友成果頁 | BizPro 歷屆成員、心得 | 需取得本人與相關單位同意，並避免捏造心得、評價或合作關係。 |
| P2 | 公告封面卡片的克制入場動畫與首頁捲動提示 | BizPro、臺大學生會 | 只採 150–250ms opacity／transform，支援減少動態偏好；不引入 Canvas 作為預設必要體驗。 |
| 暫緩 | 雙語切換與問題回報信箱 | 臺大學生會 | 待有雙語內容維護責任與正式信箱／回覆責任人後再啟用。 |
