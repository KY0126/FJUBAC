# FJUBAC 官網 CSS 與互動優化建議

**盤點日期：** 2026-08-27（GMT+8）  
**依據：** 現有 FJUBAC 藍色品牌、公開內容架構、先前研究過的學生社團官網資訊層級與已完成的可近用性原則。  
**前提：** 下列均為建議，尚未直接變更使用者未確認的頁面；非必要動畫皆應只使用 `transform` 與 `opacity`，並尊重 `prefers-reduced-motion`。

| 優先級 | CSS／互動方向 | 建議效果 | 適用位置 | 可近用性與效能條件 |
|---|---|---|---|---|
| P0 | 錨點捲動偏移 | 以 `scroll-margin-top` 避免固定導覽列遮住「五部門介紹」錨點標題。 | `/departments` 與所有章節錨點。 | 無動畫依賴；可直接改善深連結閱讀。 |
| P0 | 焦點狀態一致化 | 為導覽、卡片連結、篩選器與表單提供一致的 `:focus-visible` 外框與底色。 | 公開頁與管理頁互動元件。 | 僅在鍵盤焦點顯示，避免滑鼠操作造成視覺干擾。 |
| P0 | 表單狀態強化 | 使用 `:focus-within`、`:user-invalid` 與明確成功／錯誤色，讓招生與登入表單更容易辨識。 | `/apply`、登入、個人中心、管理表單。 | 錯誤不可只用顏色，仍保留文字說明與 `aria` 回饋。 |
| P1 | 章節揭露節奏 | 將既有的輕量揭露擴及公開資訊卡與資訊帶，使用短暫位移及淡入建立閱讀節奏。 | 首頁、公告、活動、資源、成果頁。 | 於減少動態偏好下立即顯示；不可影響內容載入。 |
| P1 | 導覽與文字連結底線動態 | 使用偽元素製作短距離底線滑入／展開，讓可點選文字更明確。 | 主導覽、卡片文字連結、頁尾連結。 | 對比充足；鍵盤焦點提供相同視覺訊號。 |
| P1 | 內容卡片互動系統 | 將首頁五部門卡片既有的微幅抬升規則，擴展為公告、活動、資源、成果卡片共用的節制互動。 | 公開內容卡片。 | 僅限 `hover:hover` 與 `pointer:fine`；觸控與減少動態不觸發。 |
| P1 | 流動字級與行長 | 擴展 `clamp()` 字級、設定內容段落的最大行長與 `text-wrap: balance` 標題，降低大螢幕行寬過長。 | 公開頁 hero、標題、FAQ 與說明段落。 | 屬漸進增強；較舊瀏覽器維持正常換行。 |
| P2 | 品牌網格／資料紋理 | 以低對比 CSS 漸層與偽元素延續資料分析意象，不需額外圖片資產。 | Hero、研究入口、空狀態與區塊背景。 | 不作為資訊承載；對比不影響文字。 |
| P2 | 顯著對比偏好 | 加入 `prefers-contrast: more` 覆寫，提高邊框、連結與可操作元件的區辨。 | 全站共用樣式。 | 屬使用者偏好；不改動預設品牌視覺。 |
| P2 | 捲動進度提示 | 在長篇公開頁加入輕量閱讀進度指示，協助理解目前章節位置。 | 部門介紹、學習地圖、公開成果。 | 不遮住固定導覽，並在減少動態偏好下採靜態變化。 |

## 建議實作順序

建議先完成 **P0 的錨點偏移、焦點一致化與表單狀態**，因為它們能直接改善鍵盤可用性、深連結與關鍵表單的操作清晰度。接著可導入 **P1 的連結提示、卡片互動與流動排版**，使現有藍色品牌更一致且不增加不必要動態。最後再視內容規模採用 P2 的背景紋理、對比偏好與捲動進度提示。

## P1 實作紀錄

P1 已完成流動排版與公開內容卡片互動。公開頁的重要標題採用流動字級與 `text-wrap: balance`，說明文字限制為舒適行長並採用漸進式 `text-wrap: pretty`；公告、活動、資源、成果、公開部門與首頁資訊卡在精細游標下提供統一的 4px 抬升、邊框與陰影回饋。觸控裝置與減少動態偏好不會觸發該懸停動態，卡片內具鍵盤焦點時仍會保留清楚的可近用性提示。已檢視首頁、公告、活動、公開成果及手機公開頁，並完成測試、型別檢查、建置與首頁五卡回歸驗收。

## P2 實作紀錄

長篇公開頁現在具有共用的固定閱讀進度條與右下角回到頂部控制：進度條以 ARIA progressbar 呈現目前位置；按鈕在捲動超過 360px 後才進入鍵盤焦點序列，點選後依使用者動態偏好平滑或立即回到頂端。P2 品牌紋理以低對比 CSS 點陣、網格與漸層組成，僅用於 Hero 與公開頁背景，不承載內容，也不降低文字對比。已完成桌機與手機檢視、實際瀏覽器捲動驗收、65 項單元測試、型別檢查、正式建置與首頁輪播回歸。

## 長篇章節目錄實作紀錄

首頁、五部門介紹、學習地圖與公開連結／資源頁現在加入共用的浮動章節目錄。桌機版固定於右側閱讀區，行動版改為右下角可展開的原生 `details` 控制；每個連結都指向頁面內實際存在的公開章節，並使用既有錨點偏移在固定導覽列下方定位。垂直長頁會依捲動標示目前章節；五部門與學習地圖的並列卡片則保留使用者選擇，避免同列卡片共享垂直座標而互相覆寫。目前於頁面底端時，自動標示最後可閱讀章節。已完成桌機深連結、行動展開／收合、目前段落、無水平溢出、鍵盤操作、66 項單元測試、型別檢查、建置、閱讀輔助與首頁輪播回歸驗收。

> 所有建議都應以真實公開內容為主體；CSS 只用於提升資訊層級、導覽清楚度與閱讀品質，而不以動態遮蔽資訊或製造虛構互動。
