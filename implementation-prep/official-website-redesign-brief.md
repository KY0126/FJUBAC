# FJUBAC 正式官網改版簡報

## 現況判斷

目前首頁以深色大幅 hero、編號索引、分鏡式大標與「FIELD NOTE」語彙組成。雖有明確的視覺個性，但資訊呈現接近品牌簡報；訪客需要理解社團、找活動、看公告或申請加入時，無法在短時間內取得清楚的官網式導引。

## 改版原則

首頁應成為社團的公開入口，而不是研究報告或提案的封面。視覺採成熟、明亮、可信賴的校園專業組織語言，使用清楚標題層級、適度留白、可掃讀卡片與直接的行動按鈕。深色與珊瑚色保留為品牌點綴，但不再以整頁深色英雄與海報式巨型文字主導閱讀。

## 方向確認與取代範圍

初步討論曾將問題界定為「網站看起來過於簡報或文件化」，並考慮把首頁調整為文件型資訊入口。使用者隨後明確確認目標不是文件，而是**正式社團官網**。因此，本改版不採用側欄檔案索引、研究報告式首頁或長篇文件型版面；改採品牌定位、公開服務、最新資訊、組織介紹與招生行動為中心的官網資訊架構。

研究檔案仍保留在 `/research`，維持其獨立研究頁身分。公告、活動與招生等公開服務頁則將在後續階段以共用導覽、淺色內容底、清楚標題層級、服務卡片與明確行動按鈕向首頁靠攏。跨裝置驗收亦會以正式官網的導覽效率、資訊掃讀與行動入口為準，而不是文件版面驗收。

## 首頁資訊架構

| 區塊 | 訪客要快速得到的資訊 | 主要行動 |
|---|---|---|
| 首屏介紹 | FJUBAC 是什麼、服務哪些學習與實作需求 | 查看招生、瀏覽近期資訊 |
| 最新動態 | 最新公告與活動是否已發布 | 前往公告、活動頁 |
| 社團特色 | 分析方法、專案實作、職涯連結 | 理解社團定位 |
| 五部門 | 組織分工與參與面向 | 認識各部門 |
| 加入 FJUBAC | 校內外招生與申請流程 | 前往申請頁 |
| 研究檔案 | 既有公開內容研究的補充價值 | 前往獨立研究頁 |

## 路由定位

`/` 為正式社團官網首頁；`/announcements`、`/events`、`/apply` 為公開服務頁；`/workspace` 與管理頁維持受保護工作區；`/research` 保留其既有「校園檔案室」風格，作為研究附屬頁而非首頁主視覺。

## 動態資訊原則

首頁的「最新公告」與「近期活動」須直接使用既有 `content.announcements.publicList` 與 `content.events.publicList` 公開查詢。若尚無真實資料，首頁應呈現簡潔的服務狀態與前往公告、活動或招生頁的入口，不得以假活動、虛構公告或假使用者內容填充。

## 初步驗收結果

新版首頁已於 1280px 桌機與 375px 行動版驗證。首頁現在以社團名稱、定位、公告／活動、五部門與招生入口形成明確的資訊與行動層級；手機版則將導覽焦點收斂為品牌與招生按鈕，其他公開服務入口保留於首屏快速導覽與後續內容。現有無公告、無活動資料維持真實空狀態，未加入虛構內容。

公告、活動與招生頁已改用共用的 FJUBAC 品牌導覽列，並以淺色資訊首屏、清楚服務標題與保留原有空狀態／申請流程的方式和首頁對齊。桌機及 375px 行動版均已驗證；行動版保留品牌與「加入 FJUBAC」行動按鈕，服務內容依序直向呈現，未見水平溢位。

官網改版後已完成型別檢查、8 個測試檔／19 項測試與正式建置。檢查最近的網路與瀏覽器日誌，未發現新的 4xx／5xx、tRPC Client Error、SyntaxError 或 API Query／Mutation Error。

官網改版後亦重新驗證 `/account`、`/workspace`、`/manage/workspace`、`/manage/recruitment` 與 `/research` 的 1280px 桌機及 375px 行動版。帳號頁、社員工作區及治理工作台仍保有原有受保護內容與空狀態；研究檔案則維持獨立的研究導覽與視覺語言，未被公開官網首頁樣式覆蓋。
