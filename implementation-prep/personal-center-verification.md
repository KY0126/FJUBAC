# 個人中心驗收註記

## 2026-08-27 本機預覽判讀

行動版預覽截圖在初始畫面顯示「正在整理你的個人中心」。最新網路紀錄顯示，已登入的 OAuth 使用者 `auth.me` 查詢約在 2.7 秒完成；截圖在該身份查詢完成、個人中心摘要查詢開始前擷取。因此此截圖反映的是短暫初始載入狀態，而非已確認的持續失敗。

同一輪的瀏覽器主控台日誌未出現個人中心或 tRPC 錯誤。未登入瀏覽器請求 `/me` 與 `personal.updateProfile` 均回應 401，確認個人資料、偏好、資源紀錄及稽核摘要不會由公開頁存取。

後續仍須於已登入的實際帳號測試一次個人資料儲存、頭像上傳、資源收藏／開啟／下載、通知已讀／封存與密碼變更的成功路徑；測試不得使用虛構社員、資源或通知資料。
